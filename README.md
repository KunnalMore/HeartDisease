# ❤️ Heart Disease Prediction App

An AI-powered web application that predicts the risk of heart disease using Machine Learning.

Built with Streamlit and a trained KNN model.

## 📌 Project Overview

This application predicts whether a person is at high or low risk of heart disease based on clinical parameters such as:

- Age
- Sex
- Chest Pain Type
- Resting Blood Pressure
- Cholesterol
- Fasting Blood Sugar
- Resting ECG
- Maximum Heart Rate
- Exercise-Induced Angina
- ST Depression (Oldpeak)
- ST Slope

The model was trained using the K-Nearest Neighbors (KNN) algorithm.

---

## 🧠 Machine Learning Workflow

1. Data Cleaning & Preprocessing  
2. One-Hot Encoding for Categorical Features  
3. Feature Scaling using StandardScaler  
4. Model Training (KNN Classifier)  
5. Model Evaluation  
6. Model Serialization using Joblib  
7. Streamlit App Deployment
